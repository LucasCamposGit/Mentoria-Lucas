# Mentoria (Next.js)

Converteu o `index.html` para um projeto Next.js mínimo.

Getting started

```bash
npm install
cp .env.example .env.local
# edit .env.local and fill the Supabase values
npm run dev
```

O projeto usa o CDN do Tailwind para facilidade. Para produção, considere instalar e configurar o Tailwind localmente.
